# Piloto de señalización digital para Microsoft Teams Rooms con Yealink MeetingBar A30 y YMCS.

El objetivo es evaluar la viabilidad de aprovechar las pantallas de salas de reunión como canal de comunicación interna durante períodos de inactividad, sin afectar la experiencia de **reuniones en Microsoft Teams.**

El piloto contempla compatibilidad, licenciamiento, administración centralizada de contenido, listas de reproducción, validación del comportamiento operativo y documentación de resultados para una posible implementación escalable. Microsoft Teams Rooms admite un modo de señalización digital activado tras un período configurable de inactividad, por lo que las pruebas se enfocan especialmente en la transición entre contenido informativo y reuniones.
